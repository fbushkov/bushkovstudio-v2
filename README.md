# bushkovstudio — сайт Филиппа Бушкова

Личный сайт студии: сервис-дизайн, продуктовый консалтинг, дизайн-системы, UX/UI-консультации.
Статический сайт без сборки: HTML, CSS и JavaScript. Работает и с диска (двойной клик по `index.html`), и на любом хостинге.

## Страницы

| Адрес | Страница |
|---|---|
| `#/` | Главная |
| `#/expertise` | Экспертиза: `#/expertise/service-design`, `/product`, `/design-systems`, `/ux-ui` |
| `#/projects` | Портфолио с фильтром категорий |
| `#/contacts` | Контакты |
| `#/philosophy` | Философия: вход, проблематика, «ЭКРО», зачем мне это, свод правил, выход |
| `#/blog` | Заглушка «раздел готовится» |

## Структура

```
index.html              разметка всех страниц
assets/
  css/
    fonts.css           подключение Gilroy
    tokens.css          цвета и размеры, светлая и тёмная темы
    base.css            сброс, кнопки, табы, теги
    layout.css          каркас: полоса меню, сайдбары, шапка, переходы между страницами
    home.css            главная и подвал
    pages.css           экспертиза, портфолио, контакты
    menu.css            большое меню
    responsive.css      адаптив и prefers-reduced-motion
  js/
    data.js             контент: меню, услуги, тарифы, кейсы, воронка
    app.js              отрисовка, меню, переходы, тема, маршруты
  img/                  логотип, фавикон, фото
  fonts/                файлы Gilroy (.woff2) — см. ниже
```

Тексты, цены и кейсы правятся в `assets/js/data.js`, разметка и поведение — в `assets/js/app.js`.

## Шрифт Gilroy

Gilroy — коммерческий шрифт, в репозиторий он не входит. Положите лицензионные файлы в `assets/fonts/`:
`Gilroy-Regular.woff2`, `Gilroy-Medium.woff2`, `Gilroy-Semibold.woff2`, `Gilroy-Bold.woff2`.
Если шрифт установлен в системе, он подхватится и без файлов.

## Запуск локально

Достаточно открыть `index.html`. Или через локальный сервер:

```bash
python3 -m http.server 8080
# http://localhost:8080
```

## Один файл для просмотра

```bash
python3 tools/bundle.py   # → dist/bushkovstudio.html: стили, скрипты и картинки внутри
```

## Публикация

В репозитории настроен GitHub Pages (`.github/workflows/pages.yml`): каждый push в `main` публикует сайт.
Один раз включите: Settings → Pages → Source: **GitHub Actions**.
Для своего домена добавьте файл `CNAME` с доменом в корень.

## Механики

- **Темы**: светлая и тёмная, выбор запоминается; по умолчанию — как в системе.
- **Меню**: на главной полоса слева открывает большое меню (смена сцены: контент гаснет, фон перетекает, пункты всплывают волной).
  На внутренних страницах клик по полосе закрепляет главное меню поверх доп. меню, снять — стрелкой «‹» или Esc.
- **Переходы между страницами**: View Transitions API (Chrome, Edge, Safari 18+), в остальных браузерах — затухание.
  «Назад» и кнопки браузера возвращают на ту же позицию прокрутки.
- **Акцент `#A945AA`** — только у кнопок и ссылок навигации; остальные элементы при наведении смещают цвет родителя.
- **Доступность**: контраст текста не ниже 4,5 : 1, управление с клавиатуры, `prefers-reduced-motion` отключает анимации.
